# Mainline V4/V5 cutover status — 2026-10-12

**Status: V4 is the default architecture on local `master`; full competition-scale implementation remains in progress.** The temporary refactor branch was removed. `src/cli.py`, `src/api.py`, package scripts, Dockerfile, Compose and root README now route to `src/medrag/`. V5 extension interfaces are present and disabled by default. Original entrypoint and deployment sources are preserved in `archive/legacy_runtime/`; older modules remain for historical replay.

The V4 core has versioned corpus identities, HTML extraction, exact-offset passages, lexical and optional dense retrieval, fusion, optional reranking, evidence verification, a bounded prepared-snapshot format, CLI and HTTP API. The service returns 503 without a verified prepared snapshot. Official snapshot preparation checks both pinned official and historical Parquet SHA-256 values and reuses raw HTML only when both corpora agree on the ID/URL pair. The current search backend keeps at most 1,000 sources in memory; it cannot serve the full official corpus.

The three-document CPU pilot passed against preserved local HTML under the historical corpus version. Ten V4 tests pass, including a synthetic rejection of conflicting official/historical ID/URL pairs and prepared-snapshot tampering. The default CLI config check matches the locally pinned official corpus SHA-256. Real official Parquet preparation, FastAPI execution, model inference, corpus-scale indexing and official submission ZIP validation were not run in the active environment; no F2 improvement or full release readiness is claimed. See `V4_SMOKE_TEST_REPORT.md`.

Four protected small-file SHA-256 values were rechecked. The nine ZIP duplicates in `CLEANUP_DUPLICATE_ZIPS.csv` were deleted after path-specific user approval and their retained identical copies were verified; `CLEANUP_EXECUTION.json` records 185,091,708 bytes released. Four of the nine removed paths were in sibling `../smoke_test/`. Fourteen historical tracked reports were moved intact to `archive/docs_pre_v4/`. No other ViBioMIR source data or indexes were changed. Large data artifacts were not fully rehashed and the existing raw HTML has no confirmed complete external backup.

This is an uncommitted local working tree. Local `master` is three commits behind `origin/master`; no pull or push was performed because remote additions overlap local working-tree files. The seven tracked files already modified by the user at baseline were preserved. Remaining implementation work is in `NEXT_IMPLEMENTATION_TASKS.md`.
